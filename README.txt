MAISON ÉLISE — LUXURY BEAUTY STUDIO TEMPLATE

FILES
- index.html: page structure and content
- styles.css: layout, responsive design and visual styling
- script.js: mobile navigation, date validation and WhatsApp booking

PREVIEW
Open index.html in a browser. An internet connection is needed for Google Fonts and the remote Unsplash photographs.

BEFORE PUBLISHING
1. Replace “Maison Élise” with the salon's real brand name.
2. In script.js, replace 254700000000 with the salon's WhatsApp number in international format, digits only. Example Kenya format: 2547XXXXXXXX.
3. Update the address, opening hours and Instagram links in index.html.
4. Confirm the service list and add real prices.
5. Replace all sample photos with images supplied or approved by the business.
6. Add a real map embed if required.

NOTES
- The booking form opens WhatsApp with a pre-filled message. It does not store appointments or provide live calendar availability.
- This is a front-end static website. No backend is required for the WhatsApp booking flow.
- The sample brand, contact details and some service descriptions are placeholders.
